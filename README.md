# RI Project — Vision-Based Robot Following

Five e-puck robots follow each other using their front cameras in a bounded
3 × 3 m Webots arena. ROS 2 controls each robot through `webots_ros2_driver`.
An independent supervisor records trajectories, following states, and contacts.

## Directory Structure

```text
RI-Project/
├── src/swarm_follow/       # ROS 2 package
│   ├── launch/            # Simulation launch file
│   ├── swarm_follow/      # Controllers, vision, PID, and metrics
│   ├── resource/          # Robot and supervisor configuration
│   ├── worlds/            # Webots arena and scenario files
│   ├── test/              # Package checks
│   ├── package.xml        # ROS 2 dependencies
│   └── setup.py           # Package installation
├── scripts/               # Batch experiment runner
├── metrics/               # Recorded results and CSV files
├── report/                # Figure generation and report files
│   └── figures/           # Generated figures
├── patches/               # Webots driver compatibility patch
└── README.md
```

`build/`, `install/`, and `log/` are generated by colcon. On WSL,
`src/webots_ros2/` contains the separately cloned Webots driver.

## Setup

The project includes instructions for Ubuntu 24.04 with ROS 2 Jazzy and for
Windows + WSL2 with ROS 2 Lyrical. The world uses the Webots R2025a format.

### Ubuntu + ROS 2 Jazzy

Install ROS 2 Jazzy, Webots R2025a, `python3-colcon-common-extensions`, and
`python3-rosdep`, then run:

```bash
git clone https://github.com/aqueiros22/RI-Project.git
cd RI-Project
source /opt/ros/jazzy/setup.bash
sudo rosdep init  # Skip if rosdep is already initialized.
rosdep update
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install --packages-up-to swarm_follow
source install/setup.bash
```

### Windows + WSL2

Run ROS 2 Lyrical in WSL (Ubuntu 26.04) and Webots R2025a on Windows.
Install `python3-colcon-common-extensions`, `python3-rosdep`, and `python3-dev`
in WSL. Clone the project as above, then prepare the patched Webots driver
from the repository root:

```bash
source /opt/ros/lyrical/setup.bash
git clone https://github.com/cyberbotics/webots_ros2.git src/webots_ros2
git -C src/webots_ros2 checkout 329486a
git -C src/webots_ros2 submodule update --init --recursive
git -C src/webots_ros2 apply ../../patches/webots_ros2-lyrical-wsl.patch
sudo rosdep init  # Skip if rosdep is already initialized.
rosdep update
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install --packages-up-to swarm_follow
source install/setup.bash
```

The clone command assumes `src/webots_ros2` is absent or empty. The
[compatibility patch](patches/webots_ros2-lyrical-wsl.patch) supports the
Lyrical build and the connection between WSL and Windows.

Set `WEBOTS_HOME` to your Windows installation directory, replacing
`YOUR_WINDOWS_USER` with your username:

```bash
export WEBOTS_HOME="/mnt/c/Users/YOUR_WINDOWS_USER/AppData/Local/Programs/Webots"
```

## Run

In each new terminal, source your ROS 2 installation and `install/setup.bash`.
Run commands from the repository root:

```bash
ros2 launch swarm_follow swarm_launch.py mode:=no_following
ros2 launch swarm_follow swarm_launch.py mode:=weak_turning
ros2 launch swarm_follow swarm_launch.py mode:=strong_turning
```

This opens Webots and starts the five robot controllers and the metrics
supervisor. Press `Ctrl+C` to stop.

| Mode | Behaviour | Angular PID gains (Kp, Ki, Kd) |
| --- | --- | --- |
| `no_following` | Base motion with visual avoidance of nearby robots. | — |
| `weak_turning` | Follow a detected robot with weaker turning. | 0.50, 0.02, 0.05 |
| `strong_turning` | Follow a detected robot with stronger turning (default). | 2.00, 0.05, 0.15 |

For a 60-second run:

```bash
ros2 launch swarm_follow swarm_launch.py mode:=weak_turning duration:=60
```

| Argument | Default | Purpose |
| --- | --- | --- |
| `mode` | `strong_turning` | Control condition. |
| `duration` | `0` | Simulated seconds; `0` runs until stopped. |
| `gui` | `true` | Set to `false` to run without a window in fast mode. |
| `webots_mode` | `realtime` | Simulation speed with the GUI: `realtime`, `fast`, or `pause`. |
| `seed` | `0` | `0` uses the poses in `arena.wbt`; other seeds generate reproducible random poses. |
| `metrics_dir` | `metrics` | Output directory, relative to the current directory. |
| `run_name` | Generated from mode, seed, and timestamp | Output subdirectory. |
| `port` | `1234` | Use a different port for each concurrent simulation. |

## Experiments and Results

Run all three modes with five generated initial configurations (seeds 1–5):

```bash
python3 scripts/run_experiments.py --scenarios 5 --duration 60
```

The script runs without a GUI by default. Add `--gui` to show Webots,
`--parallel` to run the modes concurrently, or `--seeds 0` to use the current
world configuration. Results are saved under
`metrics/<experiment>/seed<N>_<mode>/`.

The recorded evaluation contains five main scenarios (`cenario_1`–`cenario_5`)
and two special cases (`test`, `test_2`), each with three 60-second runs.
These use manually configured world poses with seed 0; the generated seeds
above do not recreate those seven configurations.

Each run produces:

- `timeseries.csv`: robot poses, detections, following states, and velocity commands at each step.
- `summary.csv`: one row per robot and an `all` row for the swarm.

| Summary metric | Meaning |
| --- | --- |
| `following_time_s`, `following_pct` | Time and percentage spent following. |
| `mean_abs_bearing_deg` | Mean absolute target bearing while following; blank when no valid samples exist. |
| `target_losses` | Interruptions in following lasting more than 0.2 s. |
| `robot_collisions` | Robot–robot contact events. |
| `wall_collisions` | Robot–wall contact events. |

In the `all` row, following time and percentage are averaged over all five
robots, bearing is averaged over all valid following samples, and losses and
wall contacts are summed. Each robot–robot contact is counted once for the
swarm and once for each participating robot. Following-specific metrics are
only used to evaluate the two following modes.

To generate figures from the recorded scenarios, install `python3-matplotlib`
and run:

```bash
python3 report/make_figures.py
```

Figures are saved in `report/figures/`.

## Rebuild

After changing package configuration or adding files:

```bash
colcon build --symlink-install --packages-up-to swarm_follow
source install/setup.bash
```

With `--symlink-install`, edits to existing Python, world, and URDF files
are used directly.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `Package 'swarm_follow' not found` | Build the workspace and source `install/setup.bash`. |
| Missing `cv2` or `numpy` | Run the `rosdep install` command from setup. |
| Webots executable not found | Set `WEBOTS_HOME` to the correct installation directory. |
| `ament_target_dependencies` build error on Lyrical | Apply the supplied compatibility patch. |
| Controllers cannot connect in WSL | Close other Webots instances, check port 1234 and the Windows firewall, and set `WEBOTS_HOST_IP` if automatic detection fails. |
| Slow simulation with Linux Webots in WSL | Use the Windows Webots installation. |
